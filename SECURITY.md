# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

**VOIRIA SASU** takes the security of Docurama and its users seriously.

If you discover a security vulnerability, please report it responsibly:

- **Email:** [security@docurama.eu](mailto:security@docurama.eu) (or [technology@voiria.com](mailto:technology@voiria.com))
- **security.txt (RFC 9116):** `https://docurama.eu/.well-known/security.txt`
- **PGP:** Available on request
- **Response SLA:** We aim to acknowledge reports within 48 hours and provide an initial assessment within 5 business days.

### What to include

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Any proof-of-concept code (if applicable)
- Your contact information for follow-up

### What to expect

1. **Acknowledgement** within 48 hours of your report.
2. **Assessment** — we will evaluate the severity and affected scope.
3. **Fix & Disclosure** — once a fix is ready, we will coordinate disclosure with you.

### Scope

This policy applies to:
- [Docurama Cloud (SaaS)](https://github.com/StalFe-Cloud/docurama)
- [Docurama Enterprise](https://github.com/StalFe-Cloud/docurama-enterprise)
- [Docurama Private Cloud](https://github.com/StalFe-Cloud/docurama-private-cloud)

### Out of scope

- Social engineering attacks
- Denial of service attacks
- Issues in third-party dependencies (please report these to the upstream maintainer)
